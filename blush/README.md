# Blush

Soft pink and berry, with DM Serif Display headings, DM Sans text and an arch around the main picture. For beauty salons, spas, weddings and florists. See `preview.jpg`.

**Use it:** copy the `blush` folder into the `themes` folder of your website,
set `THEME="blush"` in `site.conf` and run `bash build.sh`.
