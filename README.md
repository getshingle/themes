# Shingle themes

Other colors and fonts for [Shingle](https://github.com/getshingle/shingle)
websites, each in light and dark mode (three are always dark). The default
theme, concrete, oak and black iron, comes with Shingle.

| Theme | Look | |
| --- | --- | --- |
| [midnight](midnight/) | Always dark: blue-black and aqua, Space Grotesk | [demo](https://getshingle.github.io/demo/theme-midnight/) |
| [violet](violet/) | Ink and violet on white, Geist, round buttons | [demo](https://getshingle.github.io/demo/theme-violet/) |
| [slate](slate/) | Navy on cool blue-grey, IBM Plex Sans, crisp corners | [demo](https://getshingle.github.io/demo/theme-slate/) |
| [mint](mint/) | Green-teal on near-white, Figtree, soft round shapes | [demo](https://getshingle.github.io/demo/theme-mint/) |
| [noir](noir/) | Always dark: charcoal and gold, Cormorant Garamond and Jost | [demo](https://getshingle.github.io/demo/theme-noir/) |
| [clay](clay/) | Terracotta on warm white, Instrument Sans, round buttons | [demo](https://getshingle.github.io/demo/theme-clay/) |
| [lime](lime/) | Black and white with bright lime, bold Bricolage Grotesque | [demo](https://getshingle.github.io/demo/theme-lime/) |
| [paper](paper/) | Black and white, Newsreader serif headings, no color | [demo](https://getshingle.github.io/demo/theme-paper/) |
| [graphite](graphite/) | Always dark: graphite and orange, Manrope | [demo](https://getshingle.github.io/demo/theme-graphite/) |
| [blush](blush/) | Pink and berry, DM Serif Display, an arch around the main picture | [demo](https://getshingle.github.io/demo/theme-blush/) |
| [forest](forest/) | Forest green on pale stone, wide Archivo headings | [demo](https://getshingle.github.io/demo/theme-forest/) |

## Use one

1. Copy the theme's folder, for example `forest`, into the `themes` folder of
   your website.
2. Set `THEME="forest"` in `site.conf`.
3. Run `bash build.sh`.

To make your own, copy `themes/default` in your website and change the
colors. The [guide](https://getshingle.github.io/extras/themes/) shows how.
