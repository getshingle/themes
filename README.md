# Shingle themes

Other colors and fonts for [Shingle](https://github.com/getshingle/shingle)
websites, each in light and dark mode. The default theme comes with Shingle.

| Theme | Look | |
| --- | --- | --- |
| [forest](forest/) | Forest green on pale stone, wide Archivo headings | [demo](https://getshingle.github.io/demo/theme-forest/) |
| [violet](violet/) | Ink and violet on white, Geist, round buttons | [demo](https://getshingle.github.io/demo/theme-violet/) |
| [clay](clay/) | Terracotta on warm white, Instrument Sans, round buttons | [demo](https://getshingle.github.io/demo/theme-clay/) |

## Use one

1. Copy the theme's folder, for example `forest`, into the `themes` folder of
   your website.
2. Set `THEME="forest"` in `site.conf`.
3. Run `bash build.sh`.

To make your own, copy `themes/default` in your website and change the
colors. The [guide](https://getshingle.github.io/extras/themes/) shows how.
